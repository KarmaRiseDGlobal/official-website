# KarmaRise D Global website

The website presents KarmaRise D Global's Manufacturing Programmes. The first delivery is a focused landing page; the codebase leaves room for Stories, Almarise, the Women's Training Initiative, multilingual content, and communication integrations.

## Local development

1. Install Node.js 24 and pnpm 11.
2. Copy `.env.example` to `.env.local`.
3. Run `pnpm install`.
4. Run `pnpm dev`.

Use `pnpm check` for linting, type checking, and formatting checks. Use `pnpm build` to verify the production build.
